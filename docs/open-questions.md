# 作る前に確認すること

画面を作り込む前に、**法律** と **トヨタモビリティへのヒアリング** で決めておくべきことです。
答えによって機能の形が変わるもの（★）から先に確認します。

## 法律・制度（専門家に確認）

| # | 確認すること | なぜ必要か | 影響する機能 |
|---|---|---|---|
| Q1 ★ | 帰りに走るトラックは **緑ナンバー（事業用）か白ナンバー（自家用）か** | 他社の荷物を運賃をもらって運ぶには、一般貨物自動車運送事業の許可（緑ナンバー）が必要。白ナンバーなら、そのままでは有償で運べない | P1-5、事業の形そのもの |
| Q2 ★ | OuRay（運営）が **仲介だけ** か、**運送を引き受けて委託する** か | 運送を引き受けて他社に運ばせる場合は「貨物利用運送事業」の登録が必要。仲介だけなら契約は荷主と運送会社の間になる | P2-9、P4 の契約・請求の流れ |
| Q3 | 運送の契約内容を書面で残す義務への対応 | 2025年の法改正で、運送の契約時に運賃・付帯作業などを書面で交付することが求められている | P4-2 |
| Q4 | 事故・破損・紛失の補償 | 運送会社の貨物保険でどこまで補償されるか、補償の上限、約款（標準貨物自動車運送約款を使うか） | P2-13、P3-5 |
| Q5 | 手数料の受け取り方とインボイス | 運営の手数料を誰からもらうか、請求書の発行者は誰か | P1-15、P4-3 |
| Q6 | 個人情報・取引情報の扱い | 荷主の情報を運送会社に渡す範囲 | P2-11、P3-1 |

## トヨタモビリティへのヒアリング

| # | 聞くこと | 影響する機能 |
|---|---|---|
| H1 ★ | 行きに運んでいるものは何か（新車・部品・用品など）。トラックは自社か委託先か | 誰が「運送会社」として登録するか |
| H2 ★ | 車種（平ボディ・バン・キャリアカー）と荷台の寸法・積載量 | P1-3、パレット枠で売れるか（キャリアカーなら「車1台分」で売る形に変える） |
| H3 | 走っている路線・曜日・時間（定期か不定期か） | P1-6 定期ルート／P1-9 単発便の比重 |
| H4 | 帰りに荷物を積める時間の余裕（何時までに戻ればよいか、寄り道はどこまで可能か） | P2-6, P2-7 |
| H5 | 荷物の受け渡しができる場所（店舗・センターで受け取れるか、フォークリフトの有無） | P1-1 |
| H6 | 承認は誰がするか（配車担当者？ドライバー？）。スマホかPCか | P2-9、P3 の画面 |
| H7 | 運びたくない荷物・取引したくない相手の条件 | P2-5、P5-3 |
| H8 | 目標の金額（帰り便1本あたりいくらになれば導入するか） | P1-13 料金 |

## 荷主側の検証（最初の利用者候補）

- 同じ路線で荷物を送っている中小事業者（部品メーカー、卸、引越し少量、イベント資材など）
- 今いくら払っているか、日時が「便」に固定されても使うか（航空便モデルが受け入れられるか）
- 拠点への持ち込み・拠点での受け取りで使えるか（MVP は寄り道なし）

## 既存サービスとの違い（説明できるようにしておく）

帰り荷のマッチングは既存サービスもあるため、OuRay の違いを整理しておく：

- **「便」として先に空きを公開** する（荷物ごとに都度トラックを探す方式ではなく、航空券のように選んで予約）
- **大手の定期便の帰り** という信頼と、毎週同じ曜日に走る予測しやすさ
- **パレット枠単位の少量** から使える（トラック1台を借りるほどの量がない事業者向け）
